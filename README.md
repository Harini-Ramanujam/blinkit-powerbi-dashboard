# Blinkit Sales Dashboard – Power BI

## Overview
The Blinkit Sales Dashboard is an interactive Power BI project designed to analyze sales performance, outlet distribution, customer ratings, and product insights of Blinkit – India's Last Minute App.

The dashboard transforms raw business data into meaningful visual insights using Power BI, DAX, and Power Query.

---

## Features
- Total Sales Analysis
- Average Sales & Ratings
- Outlet Establishment Trends
- Outlet Size & Location Analysis
- Item Type Distribution
- Fat Content Analysis
- Interactive Filters & Slicers
- KPI Cards and Business Insights

---

## Dashboard Metrics
- **Total Sales:** $1.20M
- **Average Sales:** $141
- **Number of Items:** 8523
- **Average Rating:** 3.9

---

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Excel / CSV Dataset

---

## Key Insights
- Tier 3 outlets generated the highest sales.
- Medium-sized outlets contributed major revenue.
- Supermarket Type 1 showed maximum sales performance.
- Product category and fat content analysis helped identify customer preferences.

---

## Project Objective
To build a business intelligence dashboard that helps analyze sales performance, customer trends, and outlet efficiency through interactive visualizations.
